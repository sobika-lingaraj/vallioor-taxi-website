# Vallioor Taxi

A modern, responsive website for Vallioor Taxi services.

## Tech Stack
- **Framework**: React 19
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: Vanilla CSS

## Development

### Prerequisites
- Node.js (Latest LTS recommended)
- npm

### Installation
```bash
npm install
```

### Scripts
- `npm run dev`: Starts the development server.
- `npm run build`: Builds the project for production.
- `npm run lint`: Runs linting.
- `npm run preview`: Previews the production build.
